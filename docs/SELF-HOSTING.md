# Запуск на своём сервере (вариант Б)

Один контейнер, никаких внешних сервисов: ни Render, ни Supabase, ни
Neon. Скопировал файлы, вписал два ключа, запустил — работает.

## Что нужно от сервера

- Docker с плагином Compose (`docker compose version` отвечает).
- Свободный диск: образ качается ~80 МБ, на диске занимает ~250 МБ.
  База растёт медленно — тысяча задач это единицы мегабайт. С запасом
  под обновления образа хватает **500 МБ**.
- Исходящий интернет. **Входящие соединения, домен, сертификат и
  открытые порты НЕ нужны** — бот работает в режиме polling, то есть
  сам ходит в Telegram.

## Установка

```bash
# 1. Забрать репозиторий
git clone https://github.com/Itosyro/plan-app.git
cd plan-app

# 2. Заполнить два ключа
cp .env.server.example .env
nano .env      # TELEGRAM_BOT_TOKEN и GROQ_API_KEYS

# 3. Запустить
docker compose up -d
```

Всё. Образ скачается готовым (собран в GitHub Actions), база создастся
сама в `./data/plan.db`, схема поднимется на старте.

Проверить, что живо:

```bash
docker compose ps                         # состояние healthy
curl -s localhost:8000/healthz            # {"status":"ok",...}
docker compose logs -f app                # живой лог
```

Дальше — просто напиши боту в Telegram.

## Обновление

```bash
cd plan-app
git pull
docker compose pull && docker compose up -d
```

Миграции применятся сами. База в `./data` переживает обновление —
контейнер пересоздаётся, файл остаётся.

## Если образ не скачивается (приватный репозиторий)

GitHub Packages требует логина для приватных репозиториев. Нужен
[токен](https://github.com/settings/tokens) с правом `read:packages`:

```bash
echo ВАШ_ТОКЕН | docker login ghcr.io -u Itosyro --password-stdin
docker compose pull
```

Либо собрать образ прямо на сервере — но для этого нужно **≥4 ГБ**
свободного диска (сборка тянет `node_modules` и компиляторы):

```bash
docker compose build && docker compose up -d
```

## Мини-приложение (необязательно)

Бот в переписке работает сразу. Мини-апп (доски, канбан, календарь) —
это веб-страница, а Telegram открывает такие страницы **только по
HTTPS**. Поэтому для неё нужен публичный адрес одним из способов:

- **свой домен** → направить на сервер, поставить Caddy (сам получает
  сертификат) и проксировать на `127.0.0.1:8000`;
- **туннель** (`cloudflared`) — даёт бесплатный HTTPS-адрес без домена.

Получив адрес, пропиши его в `.env` и перезапусти:

```
MINIAPP_URL_OVERRIDE=https://твой-адрес/app/
```

Бот сам поставит кнопку «Открыть план» рядом с полем ввода.

## Бэкап

Вся база — один файл. Копировать можно на живом контейнере:

```bash
docker compose exec app sqlite3 /app/data/plan.db ".backup '/app/data/backup.db'"
cp data/backup.db ~/plan-backup-$(date +%F).db
```

## Если мало места

```bash
docker system df                  # что сколько занимает
docker system prune -af           # снести неиспользуемые образы и кэш
```

Логи ограничены (3 файла × 10 МБ) — бесконтрольно расти не будут.

## Чем отличается от управляемого деплоя

| | Свой сервер | Render |
|---|---|---|
| Получение сообщений | polling (исходящие) | webhook (входящие) |
| База | файл SQLite | Postgres (Supabase) |
| Домен и TLS | не нужны | нужны, даёт платформа |
| Миграции | сами на старте | отдельной командой |
| Засыпание | нет | free-tier засыпает |

Переключение — одна переменная `BOT_MODE`. Код общий, ветвление
только в момент старта (`app/main.py`).

**Важно:** одновременно два экземпляра (Render и свой сервер) с одним
токеном запускать нельзя — Telegram отдаёт сообщение кому-то одному, и
поведение станет случайным. Перед переездом останови старый.
