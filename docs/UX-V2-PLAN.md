# План «UX v2» — большой UX-rework + два бот-фикса

## Контекст (от пользователя)

Скриншоты/обратная связь после ночного ребеджа:
- **Бот ломается двумя путями**:
  - «Не нашёл задачу "курсовые отправки учительницы"» — intent-detector ловит false-positive: новую задачу классифицирует как **edit-команду** (delete/rename/cancel) и не находит цель. Это _ошибка ИИ_ — а не отсутствие задачи. Серьёзно: каждый раз когда пользователь говорит про "что-то по похожему", бот думает что юзер ХОЧЕТ её редактировать.
  - «Ошибка при разборе — сохранил во входящие, разберу позже». Это исключение пайплайна.
- **UI настроек drill-in**: двойной «Настройки» (большой H1 + кнопка ← Настройки) — статистика стуттера.
- **Иконка Досок в шапке Задач** — лишняя, тесно.
- **Цветовая палитра**: светло-серый/белый перепутаны; нет единой системы.
- **Нижний нав**: хочется как **Telegram Android (Material 3)** — pill-фон под активной вкладкой, больше воздуха.
- **Excalidraw**:
  - Фон-точки **не двигается с pan/zoom** — баг (тогда как «клетка» через `gridModeEnabled` следует за камерой).
  - **Двухпальцевые жесты pan/zoom не работают** — рисует выбранным инструментом.
  - Маленькие кнопки тулбара, мало цветов, нет настройки толщины — мало похоже на Miro.
- **Скопировать Miro подчистую**: палитра цветов, инструменты, толщины линий, тулбар.

## План работ

### A. БОТ — критично, в прод как можно скорее
1. **A1: Intent-detector ужесточение.** В промпте `app/ai/prompts/intent.md` добавить жёсткое требование: без явных русских глаголов «удали/закрой/отметь/верни/переименуй/перенеси» по умолчанию `intent: create`. Сейчас он слишком охотно классифицирует neutral-фразы как edit.
2. **A2: Fallback при не найденной цели.** В `app/bot/edit_executor.py` когда `find_tasks_by_query` возвращает пусто и `intent.intent` ≠ `complete/delete/reopen` (для них fallback опасен — может пересоздать) — НЕ говорить «не нашёл задачу X», а упасть в `create`-путь с исходным транскриптом. Реализация: edit_executor возвращает специальный sentinel «cant-find»; `_pipeline.py` ловит и направляет в create.
3. **A3: «Ошибка при разборе»** — добавить детальное логирование (Sentry уже подключён, если DSN установлен). Без логов диагностика наугад. Если в `/healthz` модели всё ещё gpt-oss → docs/PROGRESS объяснят как изменить через env.
4. **A4: Тесты** на false-positive intent для типичных «создающих» формулировок («курсовые отправки учительницы», «купи хлеба», «звонок завтра в 15»).

### B. ДИЗАЙН — глобальный rework
5. **B1: PRODUCT.md + DESIGN.md** для скилла impeccable (он этого требует). Зафиксировать register=product, brand voice, anti-references.
6. **B2: Дизайн-токены.** Один источник истины:
   - Нейтрали: zinc-tinted (OKLCH, без чистого #fff/#000).
   - Акцент: **один** Telegram-blue (не пурпур, не неон).
   - Радиусы: `2xl`/`3xl` для карточек, `xl`/`full` для пилюль.
   - Тени: лёгкие, тинтированные под фон (не неоновое свечение).
   - Spacing-rhythm: вариативный, не монотонный.
7. **B3: Нижний нав → Material 3.** Pill-фон под активной вкладкой (Telegram-blue/10, ring), фон бара — `bg-tg-bg` + лёгкий top-border, безопасное space-around. Лейблы под иконками. Жирный strokeWidth активной vs тонкий неактивных.
8. **B4: Settings drill-in — единый паттерн back-нав.** Использовать ту же кнопку, что для оверлеев (Доски, TaskDetail), без дублирования слова «Настройки».
9. **B5: Аудит цветов.** Просто, через `code-review` скилл: пройти по компонентам и закрепить токены `bg-tg-bg` (поверхность 0), `bg-bento-card` (поверхность 1), `bg-bento` (поверхность 2). Сейчас местами перепутано.

### C. EXCALIDRAW — Miro-style polish
10. **C1: Фон-точки следует за камерой.** Сейчас рисуется CSS-pattern на родителе → не двигается. Решение: при `onChange` снимать `appState.zoom.value` + `appState.scrollX/scrollY` и устанавливать `background-position` контейнера через CSS-переменные. Размер pattern × zoom.
11. **C2: Двухпальцевые жесты.** Проблема — pointermove с двумя tochpoints конфликтует с выбранным инструментом. Решение: при `pointerdown` с ≥2 пальцами форсить tool в `hand` (pan) на время гесты, отпускать обратно. Через imperative API: `excalidrawApi.setActiveTool({ type: "hand" })` + restore. Или TouchEvent listener на контейнере с capture, переключающий tool.
12. **C3: Толщины линий.** В Excalidraw они есть (`strokeWidth: thin/bold/extraBold`), но в UIOptions/панели не выведены явно. Кастомный quick-bar внизу: 4 кнопки толщины + 12-цветная Miro-палитра. Поверх Excalidraw, читает/пишет в `appState.currentItemStrokeColor/StrokeWidth` через `updateScene`.
13. **C4: Палитра цветов как у Miro.** 12-14 цветов в круглых пилюлях. Цвета: чёрный (off-black), белый, зелёный (#22c55e), синий (#3b82f6), красный (#ef4444), оранжевый (#f97316), жёлтый (#eab308), пурпур (#a855f7), розовый (#ec4899), бирюзовый (#06b6d4), серый (#6b7280), коричневый (#92400e).
14. **C5: Скрыть/перестроить нативный тулбар Excalidraw** под мобайл: оставить только select / pen / shape / text / arrow / hand / eraser, остальное в overflow.

## Технические заметки

- Material 3 nav-bar: использует pill-shape под активной вкладкой через CSS (`bg-tg-button/10`, `ring`) — не нужен MD3 web-component. Размер pill = round(content + 12px padding x).
- Excalidraw API: `excalidrawAPI.setActiveTool({ type })`, `excalidrawAPI.updateScene({ appState })`, `excalidrawAPI.getAppState()`. Версия 0.18.1 поддерживает.
- Cycle интент-промпта займёт минут 5 + 1-2 регрешн-теста.
