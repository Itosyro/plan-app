# PLAN Mini-App — дизайн-язык

Telegram-native + iOS. Ориентир ощущения: клиент Telegram и бот Mira;
функциональность/плавность — Todoist. Делаем **свой** дизайн в этом духе,
не копируя проприетарные ассеты.

## Поверхности и фон

- **Фон страницы** — мягкий сине-серый «песчаный» тинт (`--bento-bg: #e6eaf2`,
  светлый верхний градиент `--bento-bg-soft`), чтобы белые карточки **лифтились**,
  а не сливались. Тёмная тема — глубокий сине-чарко́л. Фон фиксирован
  (`background-attachment: fixed`), а не наследует `tg secondary-bg` (он бывает
  белым → карточки исчезали бы).
- **Карточки** — `bg-bento-card` (белый/`tg bg`), радиус `rounded-3xl`/`2xl`,
  `shadow-bento`, `ring-1 ring-black/5`.
- **Тинт-плитки** (карточки внутри панелей, чипы, счётчики) — `bg-bento`.
- **Три уровня глубины**: фон (тинт) → панель (белая, тень+ring) → плитка (тинт).
  Так разделы канбана не сливаются.

## Токены (tailwind.config.js / index.css)

- Радиусы: `2xl`=16, `2.5xl`=20, `3xl`=24, `4xl`=28. Внешнее крупнее внутреннего.
- Тени: `bento` (лёгкий лифт), `bento-lg` (drag/hover), `island` (плавающие
  элементы — bottom-nav). Низкая альфа, не драматизируем.
- Цвета: только `tg-*` переменные (наследуют тему Telegram). **Один акцент** —
  `tg-button`/`tg-link`. Без второго акцента, без «AI-фиолетового».
- Типографика: **Inter Variable** (намеренно — совпадает с клиентом Telegram;
  бан Inter из дизайн-скиллов не применяем). `font-display` (opsz 32) для
  крупных заголовков, `tabular` для счётчиков.

## Движение

- Easing: `ease-apple` (`cubic-bezier(0.4,0,0.2,1)`), `ease-spring`
  (мягкий овершут). Анимируем только `transform`/`opacity` (GPU).
- Тактильность: `active:scale-[0.94..0.99]` на всех кликабельных.
- Bottom-sheet/секции: stagger-появление (`sheet-row-in`, per-item delay).
- Sliding-капсула (BottomNav, SegmentedControl) — translateX, один элемент.

## Компоненты-паттерны

- **BottomNav** — плавающий «остров» (Mira-стиль, крупнее стокового TG):
  `rounded-[30px]`, blur, `shadow-island`, ячейки 86px, иконки 25, лейблы 12px,
  тач-таргет ≥56px. Активная вкладка — заметная пилюля `bg-tg-button/14` + ring.
- **SegmentedControl** — трек `bg-bento` + анимированная белая пилюля активного
  сегмента; иконки опциональны; тач ≥44px.
- **BottomSheetSelect** — опции-кнопки (`bg-bento`, ring, ховер), активная с
  акцентной заливкой + галкой; stagger.
- **Switch** — iOS-тумблер для булевых настроек (`presentational` режим внутри
  строк-кнопок).
- **Настройки** — Mira grouped-list: одна скруглённая карточка на секцию
  (`divide-y`), акцентные заголовки (`tg-link`, sentence-case), цветные `IconTile`.
- **Канбан** — колонка = белая панель (тень+ring) с header-разделителем;
  карточки = тинт-плитки; `DragOverlay` (снимок → белая поднятая карточка),
  `touch-action:none`, `closestCorners`.

## Правила

- ≥44px тач-таргеты. Ховер + активное состояние у всего интерактивного.
- Не сливать поверхности: соседние элементы одного цвета разделяем ring/тенью/gap.
- Пустые/ошибочные состояния — оформлены (IconTile + поясняющая копия).
